  : lblvm: Latent Variable Modeling with Logit-Beta Models
- [`efa_cont()`](https://seewooli.github.io/lblvm/reference/efa_cont.md)
  : Run an exploratory factor analysis (EFA) for bounded-continuous
  responses

  Run an exploratory factor analysis (EFA) using the discretized
  response model (DRM)
- [`cfa_cont()`](https://seewooli.github.io/lblvm/reference/cfa_cont.md)
  : Run a confirmatory factor analysis (CFA) for bounded-continuous
  responses
- [`cfa_drm()`](https://seewooli.github.io/lblvm/reference/cfa_drm.md) :
  Run a confirmatory factor analysis (CFA) using the discretized
  response model (DRM)
- [`cfa_drm_mg()`](https://seewooli.github.io/lblvm/reference/cfa_drm_mg.md)
  : Run a multiple-group (MG) confirmatory factor analysis (EFA) using
