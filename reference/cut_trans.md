# Transformation of the Threshold Parameters to the Unit Scale

Transformation of the Threshold Parameters to the Unit Scale

## Usage

``` r
cut_trans(x)
```

## Arguments

- x:

  A vector of the raw threshold parameters.

## Value

Transformed thresholds.

## Examples

``` r
# \donttest{
cut_trans(c(0,0,0,0))
#> [1] 0.2 0.4 0.6 0.8
# }
```
