# Pseudo-Root-Mean-Square-Error-of-Approximation of Difference Test (\\\_pRMSEA_D\\)

Pseudo-Root-Mean-Square-Error-of-Approximation of Difference Test
(\\\_pRMSEA_D\\)

## Usage

``` r
rmsea_drm(fit.ref, fit.comp)
```

## Arguments

- fit.ref:

  A fitted object from the reference model.

- fit.comp:

  A fitted object from the comparison model.

## Value

A list containing \\\_pRMSEA_D\\ and its 90% confidence interval.
